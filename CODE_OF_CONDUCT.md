# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith and keep discussions about the work.

Report unacceptable behaviour privately to the maintainers through a
[GitHub security advisory](https://github.com/tripaulx/tripaulx-builder-init/security/advisories/new)
(it is private), or by e-mail to Flavio Almeida Paulino at
[f1@tripaulx.com](mailto:f1@tripaulx.com?subject=%5Btripaulx-builder-init%5D%20Conduct).
