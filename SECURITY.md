# Security policy

Please **do not** open public issues for vulnerabilities.

Report privately through GitHub:
**Security → Report a vulnerability** in
[tripaulx/tripaulx-builder-init](https://github.com/tripaulx/tripaulx-builder-init/security/advisories/new).

You can also write to **Flavio Almeida Paulino** at
[f1@tripaulx.com](mailto:f1@tripaulx.com?subject=%5Btripaulx-builder-init%5D%20Security).

We acknowledge reports within 3 business days. Fixes are released as patch versions,
with a GitHub security advisory.

## Supported versions

| Version | Supported |
|---|---|
| latest minor (0.x) | ✅ |
| older | ❌ |
