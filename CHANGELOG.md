# Changelog

All notable changes to **tripaulx-sdk** and the project template are recorded here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the
project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- `tripaulx.core`:
  - `BaseModel` (UUID primary key, audit timestamps, soft delete) and `AliveManager`;
  - `TenantMiddleware`, which answers `/healthz` and `/readyz` before tenant lookup and skips static files;
  - log redaction filter;
  - `TenantTestCase`;
  - `AppSettings` for the `TRIPAULX` options dict.
- `tripaulx.tenants`:
  - `Workspace` and `Domain` models;
  - workspace slug rules with reserved names;
  - subdomain helpers;
  - the idempotent `bootstrap_workspace` command.
- `tripaulx.accounts`:
  - `AbstractTripaulxUser` (e-mail login, `email_verified`, `password_login_disabled`, `role`);
  - `UserManager`;
  - `TripaulxUserAdmin`.
- `tripaulx.settings`: helpers for env loading, app lists, middleware, logging and hosts.
- pt-BR translations for every SDK app.
- Copier template:
  - settings split into chunks, with Django 6.1 `MAILERS`;
  - `users` app;
  - `./start` and `./pg` scripts;
  - smoke tests.
- CI:
  - lint, file size and translation checks;
  - SDK test matrix (Python 3.12/3.13 × Django 6.0/6.1 × PostgreSQL 16/17);
  - end-to-end template render;
  - gitleaks.
- Release workflow with PyPI Trusted Publishing.
- README in English and pt-BR with diagrams in the tripaulx design system:
  - hero, architecture, request flow, SDK apps, accounts and roadmap;
  - light and dark versions of each;
  - generated by `scripts/readme_art`, with the Inter typeface embedded.
